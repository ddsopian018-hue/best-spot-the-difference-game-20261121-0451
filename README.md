**Twin Canvas** — a spot-the-difference game with five original hand-drawn scenes (Harbour Dawn, Night Market, Jungle Temple, Moon Garden, Starlight Station), seven hidden differences in each, for 35 finds in a full game. Every scene is drawn procedurally on canvas — no copied art, no image files, no network requests. Click a difference on either picture to ring it with a green tick; chained finds build a combo worth more points, wrong clicks cost 25 points and break the combo, and three hints per level (50 points each) pulse a ring around one unfound difference. Each level runs against a 2:30 timer with a time bonus on clearing it, and the best score is saved in localStorage. Mouse and full keyboard play (arrow keys move the crosshair, Enter clicks, H hint, P pause, M mute), synthesized WebAudio sounds, and level-clear / game-complete screens with the final tally.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the game plays offline from its own files, no build step.
